# 3.3.0

- Faster fixpoints: direct inputs live in bucketed ledger btrees; interning
  descends once per candidate from a parallel pre-intern partition with sorted
  bulk writes; emit-time dedup probes the head master only while duplicates
  dominate; relations a stratum only reads get static sorted-run indices.
- Remove the M7 rank-witness sidecar, which nothing consumed, with its
  `rank-witness-state` and `dump-ranks` actions.
- Add per-phase fixpoint timers and a run timeline (`SLOG_PHASE_TIMES`).
- Fold in the 3.2.0 line: native macOS builds, daemon commands in place of
  action plugins, debugger breaks and logpoints, REPL and diagnostic fixes.
