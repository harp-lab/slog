# 3.2.0

- Support native macOS builds using Apple Clang and an external OpenMP runtime,
  including the terminal frontend, daemon, freezer, and cached rule plugins.
  Homebrew LLVM is available as an explicit alternative toolchain.
- Share native toolchain settings and cache invalidation across build paths.
- Add macOS physical-memory detection, graceful RSS limits, and concurrent
  external SMT solver spawning.
